# 밀리의서재 좌우 독서 프로필

사용자 요청: V50S 듀얼스크린에서 밀리의서재를 책처럼 두 페이지로 읽는다. 앱이 현재 열린 실제 V50S로 시험한다. 사용자는 PDF 뷰어의 ‘가로 모드 두 쪽 보기’가 있으며 켜둔 상태라고 확인했다.

기존 게임용 회전·LG 화면 확장·복원 로직을 재사용한다. 게임은 가로 상하 배치를 유지하며, 밀리의서재는 세로로 펼친 커버/본체에 좌우 페이지를 배치한다. ReGene 런처에 독서 실행 버튼을 추가한다. 읽기 뷰어에서만 확장하고 서재·다른 앱·화면 꺼짐·커버 닫힘에서는 해제한다. 자동 배치를 끄면 각 프로필의 기본 자세를 고정한다.

밀리 앱을 수정하거나 책 데이터를 추출하지 않는다. 원래 두 쪽 보기를 이용한다. 캡처 보호는 유지하고 실제 페이지/터치/힌지 배치는 사용자 관찰로 확인한다. 초기 지원 Activity는 설치본에서 확인한 PdfViewerActivity와 MillieViewerActivity 두 개다. 웹툰/스토리/서재는 대상에서 제외한다. EPUB 두 쪽 동작은 PDF 결과만으로 보장하지 않는다.

순수 Java 프로필 테스트로 기존 네 에뮬레이터의 자세 및 내용 판정을 보존하는지 검사한다. 실기기에서는 논리 크기, 뷰어 자체 DOUBLE 설정, 확장 유지, 홈/복귀, 커버/회전 복원 및 페이지 넘김을 구분해 기록한다.
