# ReGene 0.1.9 화면 배치 대기 이유

자동 자세 판단을 켠 상태에서 Azahar 게임이 계속 foreground인데 가로 자세를 감지하지 못해 확장을 해제하면, 0.1.8은 `대상 앱 밖: 원래 화면 설정 복원`을 표시했다. 이 메시지는 현재 게임을 보고 있는 상황을 잘못 설명했다. 이후에도 대기 원인을 갱신하지 않았다.

0.1.9는 화면 배치 조건을 바꾸지 않고 비활성 상태의 이유를 표시한다. 다른 앱, 게임/편집 화면 대기, 화면 꺼짐, 커버 꺼짐, 가로 자세 대기, 게임 화면 준비를 구분한다. 같은 이유는 반복 저장하지 않는다. 활성화되면서 이미 확장된 화면을 유지하는 경우에도 유지 상태를 표시한다.

## 실기기 확인

- 업데이트 전 센서 서비스에서 ReGene의 LGE Gravity Sensor 연결은 active였고 약200ms 간격의 값 x=-0.47,y=0.01,z=9.80이었다. 평평한 자세 값이며 센서 중단 증거는 아니다. 해당 시점 실제 가로 자세 변화 로그는 없었다.
- V50S에 versionCode10/versionName0.1.9 설치. 빌드 및 APK v2/v3 서명 검증 통과.
- 자동 자세 판단true로 Azahar 시험판을 다시 실행했다. foreground는 EmulationActivity인데 확장 없는 상태에서 status가 `가로 자세 감지 대기: 폰을 들어 가로로 돌려주세요.`로 갱신됐다. 로그에서도 같은 문장을 확인했다.
- Azahar PID29465, Bluetooth STATE_CONNECTED 유지. Citra의 기존 자동 숨김 복원 소유권은 유지한다.
- APK SHA256: `D2686EFDE18A4A82C3D8DCF22B3E8CF18E19BA45137552852E9CAE1CC5061C82`.

실제 회전으로 가로 감지와 화면 확장이 이어지는지, 이 버전의 활성 상태 유지 메시지 및 각 다른 대기 분기의 실기기 검증은 아직 남았다. 상태 설명의 수정이며 회전 동작을 새로 통과했다고 판단하지 않는다.
