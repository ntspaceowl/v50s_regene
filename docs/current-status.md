네 앱의 여러 컨트롤러 및 기존 수동 숨김 상태 보존을 모든 조건에서 검증한 것은 아니다. 실제 케이스 탈착/재연결, 다른 앱의 PC 없는 사용, 장시간 안정성의 전체 범위는 아직 확인되지 않았다. 최신 Citra 화면·종료 수정은 사용자 통과다. 각 상세 기록은 해당 experiment 문서 및 drastic-max-fit.md, max-fit-profiles.md를 참조한다.

실사용 목록·중복 설치 삭제·작업 캡처 정리는2026-10-04-usability-fixes.md를 참조한다. 최신 실패 보고가 이전 Citra 통과 기록보다 우선한다.

최신 통과 응답은 Citra의 수정된 화면 비율과 종료 후 확장 해제 두 항목에 대한 확인이다. 추가 BT 수동 시험을 요청하지 않는다. Azahar 자동 점검에서는 PID11282로 실행 및 재실행이 유지됐으나 첫 게임 종료 후 목록 화면이 검게 남았다. HOME 후 목록 재진입으로 복구됐고, 이어진 게임 실행·정상 종료에서는 목록이 바로 표시됐다. 이 간헐 현상과 이전 EGL 초기화 충돌의 원인은 미확정이며 해결됐다고 간주하지 않는다.


## 0.1.14 및 Azahar 후속 보완

Azahar의 최종 APK는 기존 native 8개와 동일하고 Android UI만 보완했다. 게임 종료 때 목록 새로고침을 요청하고, 화면 축소 후 살아 있는 MainActivity가 한 번만 재생성된다. 이미 초기화된 상태에서는 시작 splash를 반복하지 않는다. ReGene는 Azahar 확장을 확인한 뒤 실행 중인 기존 작업을 본체로 가져와 LG의 커버 쪽 입력 포커스를 복구한다. 다른 에뮬레이터의 런처 작업 구조는 다를 수 있어 이 복구 동작은 Azahar에만 적용한다. 네 앱 최초 실행은 본체 display0을 지정한다.

최종 반복 시험: PID23910에서 화면 꺼짐/켜짐을 포함한 게임 실행·정상 종료 3회 모두 첫 목록 조회에서 Kirby 목록이 표시됐다. 별도 새 프로세스 PID27916에서 두 게임 화면 출력과 메뉴, 종료 후 목록도 확인했다. 시험 중 새 native fatal은 없었다. 설정은 graphics_api=2(Vulkan), resolution_factor=2다. 이는 이전 OpenGL EGL 초기화 실패 경로를 사용하는 설정을 바꾼 것이며 원본 OpenGL 엔진의 모든 오류를 수정했다는 뜻은 아니다.

사용자가 PC 분리/커버 닫았다 열기 시험은 DraStic만 했다고 확인했다. 나머지 세 앱의 실제 물리 전환과 장시간 성능은 미확인이다. PC 없이 실행되는 앱 구조와 실제 USB 분리 결과는 구분한다. 기본 상하 배치/입력 통과를 다시 요청하지 않는다. auto_pose=true, restore_pending=false로 복원했고 폰은 ReGene 목록으로 돌아왔다.
