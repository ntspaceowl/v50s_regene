# 최신 실기기 상태 (2026-10-04)

휴대폰의 ReGene는0.1.12/code13이다. WideMode 앱 없이 LG API를 호출한다. 다음 상태는 과거 조사 기록보다 우선한다. 사용자가 듀얼스크린 케이스에서 연결할 수 없는 USB-C 패드 검증을 제외했다. 임시 강제 가로 설정을 끝내고 auto_pose=true로 복원했다.

| 앱 | 실제 사용자 시험 | 남은 핵심 항목 |
|---|---|---|
| Azahar 분리 시험판 | 커버 상단/본체 하단, 손가락 터치, 확인·취소 및 방향 조작 통과. 실제 BT 해제/재연결 숨김·복원 별도 관찰. 최대 비율 배치 및2배 설정 후 실행 캡처 확인 | 확대 후 손가락/물리 배치, 장시간 성능, 커버 재연결, PC 없이 사용 |
| melonDS 분리 시험판 | 배치·손가락 터치·패드 입력·회전 복구·BT 해제/재연결 모두 사용자 통과. 최대 비율 배치 및OpenGL2배 설정 후 실행 캡처 확인 | 확대 후 손가락/물리 배치, 장시간 성능, 커버 재연결, PC 없이 사용 |
| 원본 DraStic + MX FLEX DUO 매핑 | R3 메뉴, 전체 가상패드/메뉴 숨김, 배치·터치·입력, BT 해제/재연결, PC 분리/홈/화면·커버 닫았다 열기 사용자 통과 | 확대 배치 및2배3D 옵션 적용 후 실제 손가락 재확인. 활성 특수 버튼 별도 확인 |

네 앱의 여러 컨트롤러 및 기존 수동 숨김 상태 보존을 모든 조건에서 검증한 것은 아니다. 실제 케이스 탈착/재연결, 다른 앱의 PC 없는 사용, 확대 후 실기기 확인이 남아 전체 목표는 미완료다. 각 상세 기록은 해당 experiment 문서 및 drastic-max-fit.md, max-fit-profiles.md를 참조한다.
