# DraStic 패널 최대 맞춤 (2026-10-04)

## 후속 화면 모드 수정

사용자가 소울실버 시작 장면에서 상단이 하단까지 크게 침범하는 스크린샷을 제공했다. 실행 중인 하트골드에서 `Select Screen Layout → Landscape 1:1`을 선택하자 기존 저장 최대 배치가 정상으로 돌아왔다. `Landscape 1:1` 편집기의 게임별 좌표도 유지되어 있었으며 현재 게임으로 저장했다. General Settings의Default Layout은Landscape 1:1, High-Resolution 3D Rendering은ON을 확인했다. 다른 화면 모드에서는 이 맞춤 배치를 사용하지 않는다.

소울실버로 게임을 바꾼 뒤 정상 두 패널 배치를 캡처로 확인했다. 이어 정상Quit 후 프로세스force-stop, ReGene 실행, 소울실버 새 실행도 확인했다. ROM 및 게임 세이브는 수정하지 않았다. 기존 앱의 화면 모드 선택을 맞춘 것이며 APK 변경은 없다. 현재 정상 배치가 사용자 제공 실패 사진과 달라졌지만 실패 사진 당시 선택된 모드나 과도기 surface 상태를 직접 읽은 것은 아니므로 원인을 하나로 확정하지 않는다.

네 앱 모두 커버를 닫았다 열어도 문제없다는 최신 사용자 응답을 통과로 기록한다. 이는 이번 화면 크기 수정에 대한 통과와는 구분한다.

사용자는 듀얼스크린 케이스 사용 중 USB-C 패드를 연결할 수 없으므로 USB-C 검증을 제외했다. 앞서 요청한 PC 분리, 홈 복귀, 화면 껐다 켜기 및 커버 닫았다 열기의1·2·3은 모두 사용자 통과다. 실제 케이스 탈착 시험으로 확대하지 않는다.

화면 크기: 현재 dumpsys display의 실제 본체/커버는 각각1080×2340이다. 가로 패널은2340×1080이고 확장 캔버스는2340×2160이다. DS의256:192=4:3 비율을 유지한 패널 최대 크기는1440×1080이다. 폭을2340까지 늘리면 높이가1755가 되어 한 패널에 들어가지 않는다.

기존 게임 화면은 약1130×848로 위아래 여백이 남았다. ReGene0.1.11/code12에서 선택한 DraStic의 정확한 Customizer Activity도 확장 대상으로 포함했다. 편집 중에만 자동 자세를 잠시 끄고 두 화면짜리 편집 캔버스를 확보했다. 다른 DraStic 설정/메뉴는 확장 대상으로 추가하지 않았다.

Landscape 1:1의 각 화면에 기본 도구의50% 높이(두 패널 중 한 패널), 중앙 정렬과 위/아래 정렬을 적용하고 원래 비율을 유지했다. 전역과 현재 게임의 별도 레이아웃을 모두 저장했다. 전역 저장만으로는 기존 게임별 레이아웃이 바뀌지 않았으므로 게임별 저장 후 게임 화면을 다시 검증했다.

실제 안정된2340×2160 게임 캡처 drastic-fit-hires-settled.png에서 두 영상의 색 영역 폭은1437픽셀(x413..1849)이다. 패널 경계의 작은 검은 틈을 제외하고 상단 영상은 캔버스 위쪽, 하단 영상은 아래쪽 끝까지 채운다. 편집기 좌표와 게임 결과를 시각적으로 확인했으며 nominal1440×1080과 작은 경계/반올림 차이는 있다. 게임 GL 영역의 중앙 정렬이어서 노치/시스템 영역을 포함한 물리 패널 중앙과 수십 픽셀 차이는 있을 수 있다.

Video Settings의 High-Resolution 3D Rendering을 OFF→ON으로 설정하고 체크=true를 재확인했다. DraStic는2배3D 렌더링 옵션이며3배 선택지는 제공하지 않는다. 자동 프레임스킵과 다른 렌더링 옵션은 기존값을 유지했다. 메뉴형 튜토리얼만으로 실제3D 장면의 지속 성능을 검증했다고 주장하지 않는다. 개발자 설명: https://drastic-ds.com/viewtopic.php?p=11282

변경 후 하단 게임의 터치 버튼에 ADB 홀드를 보내 설명 문장이 다음으로 진행했고, 두 화면과 배치를 유지했다(drastic-fit-touch-result.png). 이 결과는 새 좌표의 ADB 터치 검증이며 실제 손가락 재확인은 요청한다. 컨트롤러가 잠들어 연결되지 않은 캡처에서는 기존 가상패드가 복원돼 일부 버튼이 확대된 영상 가장자리에 겹친다. 컨트롤러 연결 중 전체 숨김은 앞선 시험에서 통과했으나 이번 크기 변경 후 재확인은 별도다.

끝으로 auto_pose=true를 원래대로 복원하고 ReGene의 DRASTIC 실행으로 게임에 돌아왔다. 설치 APK SHA256556DAF7A6EB4122CAB9C03162832C791F1ABF0ECF679B9E878A7B557CFFC0928, 빌드와 v2/v3 서명 검증 통과. 원본 DraStic APK/ROM/세이브를 변경하지 않았다.
