# 실사용 목록 정리와 Citra 화면 복구

사용자는 최대 배치 적용 후 melonDS와 Azahar의 물리 배치·손가락·패드 시험을 통과했다. Citra는 화면이 작고 상단이 잘리는 캡처, 종료 후 확장 잔류를 보고했다. 이 보고가 앞선 전체 통과 기록보다 우선한다.

ReGene0.1.13/code14는 실사용 버튼을Citra/Azahar/melonDS/DraStic 네 항목만 표시한다. 원본/수정본 선택과 수동 Citra 숨김 시험 버튼을 제거했다. 원본 Citra/Azahar/melonDS 및WideMode 설치본은삭제했다. 기존 앱 데이터는uninstall -k로 보존했고, 현재 사용하는 네 앱의 ROM/세이브는 삭제하지 않았다. 내부 패키지 ID는 업데이트와 데이터 보존을 위해 그대로다.

LG getWideScreenMode가false인데 논리 화면은2160×2340으로 남는 경우를 실기기에서 확인했다. LgWide는 기본 디스플레이의 논리 크기와 물리 모드 크기도 비교한다. 비활성 상태에서 회전 설정 소유권과 별개로 확장을 해제하며, 해제를 방향 유지 창 제거 전에 요청한다. 정상 HOME 시험에서 두 패널 모두1080×2340으로 복원됐다. 자동 자세 판단은시험 종료 후true로 복원했다.

Citra 기존surfaceChanged는게임 시작 후의 크기 변경을 무시했다. 회전 뒤2340×2160 표시 영역에2160×2340 버퍼가 남는 것을SurfaceFlinger에서 관찰했다. 콜백에서SurfaceChanged를 전달하고, 실행 중이면SetDisplayInfo와WindowChanged를 갱신하도록 수정했다. 초기 게임 로딩 전에는후속 갱신을 건너뛴다. 최종 실행 캡처에서상단1800×1080 at270,0, 하단1440×1080 at450,1080이 출력됐다. 원본 세로용 확대 커스텀 설정은비활성화했다. 이 자동 시험은사용자의 최종 물리 회전 확인을 대신하지 않는다.
