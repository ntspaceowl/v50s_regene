# 독서 실행 세션 (2026-10-06)

ReGene 0.1.19/code20은 밀리·리디의 확장 권한을 ReGene에서 시작한 독서 세션으로 한정한다. 해당 앱에 처음 진입한 뒤 HOME 또는 다른 앱의 Activity가 전경에 오면 서비스를 종료하고 확장·회전 상태를 복원한다. 같은 앱의 서재/설정 이동은 세션을 유지하며 실제 읽기 화면에서만 확장한다. 기존 게임의 HOME/복귀 동작은 바꾸지 않는다.

LaunchSession은 각 ACTIVITY_RESUMED 이벤트를 처리한다. 한 번의 조회 안에서 HOME과 빠른 직접 재실행이 함께 관찰되어도 종료 판정을 되돌리지 않는다. 시작 전 이벤트와 뒤늦게 도착한 오래된 이벤트는 무시한다. LG 커버 런처는 세션 종료 대상에서 제외한다. 대상 앱에 진입하지 못한 실행은 15초 뒤 종료한다.

순수 Java 회귀 시험은 초기 실행, 같은 앱 이동, 커버 런처, HOME/빠른 직접 복귀, 새 ReGene 실행, 다른 앱 전환, 실행 실패 대기 제한 및 기존 게임 유지 규칙을 검사한다. 전체 7개 시험과 빌드·APK v2/v3 서명 검증이 통과했다.

실기기에서 리디 ComicBookReaderActivity와 밀리 PdfViewerActivity 각각 다음 경로를 확인했다.

| 실행 경로 | 논리 화면 | 제어 상태 |
|---|---|---|
| ReGene 독서 버튼 | 2160×2340, land, ROTATION_0 | controller_running=true, restore_pending=true |
| HOME 이후 실제 앱 런처로 직접 실행 | 1080×2340, port, ROTATION_0 | controller_running=false, restore_pending=false |

직접 실행 검증에는 설치된 실제 MAIN/LAUNCHER Activity를 명시했다. 패키지만 지정한 암시적 am start는 해석에 실패했으므로 검증 근거에서 제외했다. 마지막 기기 상태는 밀리 직접 실행이며 확장과 제어 서비스가 종료된 상태다.

직접 실행은 본체의 원래 화면으로 돌아간다는 뜻이다. 앱 자체의 가로 두 쪽 보기 설정은 유지하므로 사용자가 직접 가로 회전하면 한 패널에서도 두 쪽이 표시될 수 있다. 같은 활성 독서 세션 안에서 앱 아이콘을 다시 누르는 동작 자체는 실행 출처를 식별하지 않는다. HOME/다른 앱으로 나간 뒤의 직접 실행을 구분한다.

밀리의 실제 좌우 표시·터치는 이전 사용자 통과를 유지한다. 리디의 실제 패널 표시·페이지 넘기기 사용자 관찰은 아직 대기 중이며 이번 논리 크기 확인으로 대체하지 않는다. 캡처 보호와 책 데이터는 변경하지 않았다.
