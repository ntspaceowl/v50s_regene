# V50S ReGene

LG V50S에서 에뮬레이터를 선택하고 가로로 돌리면 커버에 상단 게임 화면, 본체에 하단 터치 화면과 조작 버튼을 표시한다. WideMode 앱 없이 LG 화면 확장 API를 호출한다.

현재 설치본은 ReGene 0.1.19/code20이다. 목록에는 Citra, Azahar, melonDS, DraStic과 밀리의서재·리디 독서 버튼을 표시한다. 중복 설치본과 WideMode는 제거했으며 ROM/세이브는 보존했다. 각 게임 화면은 패널 높이에 맞추고 원래 비율을 유지한다. 3D 렌더링은 2배로 설정했고 Azahar는 Vulkan을 사용한다.

네 앱의 물리 상하 배치·입력·BT 가상패드 숨김/복원은 사용자 확인을 통과했다. Citra의 화면 잘림과 종료 후 확장 잔류 수정도 통과했다. 후속 Azahar에서는 게임 종료 후 목록 화면 재구성 및 화면 켜짐 뒤 본체 입력 포커스 복원을 보완했다. 최종 빌드의 같은 프로세스 실행·종료 3회, 새 프로세스 실행·종료 및 화면 꺼짐/켜짐 시험을 확인했다. 모든 게임·장시간 부하·케이스 탈착을 보장하는 결과는 아니다. 최신 근거는 docs/current-status.md와 docs/completion-audit.md를 참조한다.

## 사용

앱 사용 정보, 시스템 설정 변경, 다른 앱 위 표시 권한을 한 번 허용한다. Citra의 패드 자동 숨김에는 별도의 접근성 권한도 필요하다. ReGene에서 앱을 선택하고 해당 앱에서 게임을 고른다. 자동 배치가 켜진 상태에서 폰을 들어 가로로 돌린다. 알림 또는 앱의 중지 버튼으로 제어를 끝낸다.

처음 설정한 뒤 제어는 폰 안에서 동작한다. ReGene에서 앱을 실행하면 본체 디스플레이를 지정한다. 가로 게임 화면에서 확장하고 홈/목록/다른 앱에서는 확장을 해제한다. 외부 패드를 연결하면 전체 가상패드를 숨기며, 마지막 패드가 분리되면 기존 표시 상태를 복원한다. USB-C 패드는 듀얼스크린 케이스에서 연결할 수 없으므로 사용자 요청으로 검증에서 제외했다.

## 빌드와 설치본

Windows PowerShell에서 ./app/build.ps1을 실행한다. Android SDK와 JBR 경로는 스크립트 상단에 있다. 출력은 app/build/regene-debug.apk이며 개발 서명키 app/build/debug.keystore를 유지한다. 현재 설치 가능한 APK는 releases에 앱별 하나씩 있다. 원본 ROM과 세이브는 포함하지 않는다.

Azahar·melonDS의 Android 코드 보완과 Citra 빌드 경로는 docs의 experiment 문서 및 docs/patches에 기록했다. Azahar 최종 보완은 docs/patches/azahar-library-splash.patch에 있다. 네이티브 라이브러리는 기존 설치본과 바이트가 동일하다. 현재 적용 패치와 재빌드 기준은 [빌드 자료 안내](docs/build-inputs.md)에 정리했다. APK·서명 키·외부 소스는 Git에 포함하지 않는다.

회귀 검증은 `./app/test.ps1`로 실행한다. 종료 단계의 오류 격리, 전경 이력, 독서 실행 세션, 회전 감지, Citra 대상 분리, Citra 빌드의 LF/CRLF 레지스터 할당을 검사한다. 코드 리뷰에서 발견한 수정과 정리 내역은 [2026-10-05 리뷰](docs/code-review-2026-10-05.md)를 참조한다.

## 확인 범위와 남은 검증

네 앱 모두 커버 닫기·열기와 최종 화면 크기를 사용자 확인했다. DraStic은 실제 PC 분리도 통과했고 제어 서비스에는 PC에 연결하는 코드가 없다. 화면 배치는 전역 설정이며 DraStic 하트골드·소울실버의 별도 배치는 제거했다. 소울실버 수동 가상패드 숨김을 복원하고 새 실행에서도 표시를 확인했다. 0.1.15에서 Citra 접근성 권한 상태 표시와 권한 누락 시 설정 안내를 추가했다. 실제 서비스 연결 및 가상패드 복원을 확인했다. 최종 완료 감사는 docs/completion-audit-2026-10-05.md를 따른다.

현재 설치된 네 앱과 설정한 컨트롤러의 실사용 경로를 완료했다. 다른 게임의 장시간 부하와 여러 물리 패드 동시 연결은 추가 검증 범위다. 서비스의 재시도는 최대 6회/15초, 이후 60초 대기다. 시스템 강제 종료 직후 회전 복원은 보장하지 않으며 다음 서비스 시작에서 저장한 회전 상태를 복구한다.

## 밀리의서재 독서

ReGene에서 ‘밀리의서재 · 독서 실행’을 선택하고 앱의 두 쪽 보기를 켠다. 기기는 책처럼 세로로 펼친다. PDF 뷰어에서 커버 왼쪽·본체 오른쪽 한 페이지씩 표시와 실제 손가락 넘기기를 사용자 확인했다. 첫 표지는 한 쪽으로 표시될 수 있다. 같은 앱의 서재에서는 확장을 해제하고 읽기 화면으로 돌아오면 재개한다. 홈이나 다른 앱으로 나가면 독서 제어가 종료된다. 다시 확장하려면 ReGene에서 실행한다. 자동 배치를 끄면 독서는 세로, 게임은 가로로 유지한다. 책 앱의 캡처 보호와 원본 데이터는 변경하지 않는다. EPUB 및 다른 책 형식의 실제 두 페이지 출력은 아직 시험하지 않았다. 상세는 [독서 검증 기록](docs/millie-experiment.md)을 따른다.

## 리디 독서

ReGene의 ‘리디 · 독서 실행’을 선택하고 세로로 펼친다. 만화/PDF/EPUB 읽기 화면에 밀리와 같은 좌우 확장을 적용한다. 가로 모드 두 쪽 보기를 앱에서 켜두면 된다. 리디 26.9.1의 열린 만화에서 2160×2340 확장과 HOME 이후 제어 종료를 확인했으며 실제 페이지 배치·넘기기는 사용자 관찰 대기다. 앱의 설정과웹툰·서재는 확장 대상에서 제외한다. [검증 기록](docs/ridi-experiment.md)을 따른다.

## 독서 실행 경로 (0.1.19)

밀리와 리디의 듀얼스크린 확장은 ReGene에서 시작한 독서 세션에만 적용한다. 홈이나 다른 앱으로 나가면 서비스와 확장·회전 제어가 종료된다. 이후 앱 아이콘으로 직접 실행하면 본체의 원래 화면을 사용한다. 두 앱 모두 ReGene 실행 2160×2340, HOME 이후 직접 실행 1080×2340을 실기기에서 확인했다. 게임의 HOME/복귀 동작은 유지한다.

책 앱 자체의 두 쪽 보기 설정은 변경하지 않는다. 따라서 직접 실행도 가로로 돌리면 앱 설정에 따라 두 쪽이 보일 수 있다. 세로 직접 실행과 ReGene의 좌우 확장을 구분한다. [실행 세션 검증](docs/reading-session.md)을 참조한다.
