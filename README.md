# V50S ReGene

LG V50S에서 에뮬레이터를 선택하고 가로로 돌리면 커버에 상단 게임 화면, 본체에 하단 터치 화면과 조작 버튼을 표시한다. WideMode 앱 없이 LG 화면 확장 API를 호출한다.

현재 설치본은 ReGene 0.1.14/code15이다. 목록에는 Citra, Azahar, melonDS, DraStic만 표시한다. 중복 설치본과 WideMode는 제거했으며 ROM/세이브는 보존했다. 각 게임 화면은 패널 높이에 맞추고 원래 비율을 유지한다. 3D 렌더링은 2배로 설정했고 Azahar는 Vulkan을 사용한다.

네 앱의 물리 상하 배치·입력·BT 가상패드 숨김/복원은 사용자 확인을 통과했다. Citra의 화면 잘림과 종료 후 확장 잔류 수정도 통과했다. 후속 Azahar에서는 게임 종료 후 목록 화면 재구성 및 화면 켜짐 뒤 본체 입력 포커스 복원을 보완했다. 최종 빌드의 같은 프로세스 실행·종료 3회, 새 프로세스 실행·종료 및 화면 꺼짐/켜짐 시험을 확인했다. 모든 게임·장시간 부하·케이스 탈착을 보장하는 결과는 아니다. 최신 근거는 docs/current-status.md와 docs/completion-audit.md를 참조한다.

## 사용

앱 사용 정보, 시스템 설정 변경, 다른 앱 위 표시 권한을 한 번 허용한다. Citra의 패드 자동 숨김에는 별도의 접근성 권한도 필요하다. ReGene에서 앱을 선택하고 해당 앱에서 게임을 고른다. 자동 배치가 켜진 상태에서 폰을 들어 가로로 돌린다. 알림 또는 앱의 중지 버튼으로 제어를 끝낸다.

처음 설정한 뒤 제어는 폰 안에서 동작한다. ReGene에서 앱을 실행하면 본체 디스플레이를 지정한다. 가로 게임 화면에서 확장하고 홈/목록/다른 앱에서는 확장을 해제한다. 외부 패드를 연결하면 전체 가상패드를 숨기며, 마지막 패드가 분리되면 기존 표시 상태를 복원한다. USB-C 패드는 듀얼스크린 케이스에서 연결할 수 없으므로 사용자 요청으로 검증에서 제외했다.

## 빌드와 설치본

Windows PowerShell에서 ./app/build.ps1을 실행한다. Android SDK와 JBR 경로는 스크립트 상단에 있다. 출력은 app/build/regene-debug.apk이며 개발 서명키 app/build/debug.keystore를 유지한다. 현재 설치 가능한 APK는 releases에 앱별 하나씩 있다. 원본 ROM과 세이브는 포함하지 않는다.

Azahar·melonDS의 Android 코드 보완과 Citra 빌드 경로는 docs의 experiment 문서 및 docs/patches에 기록했다. Azahar 최종 보완은 docs/patches/azahar-library-splash.patch에 있다. 네이티브 라이브러리는 기존 설치본과 바이트가 동일하다.

## 확인 범위와 남은 검증

DraStic은 실제 PC 분리와 커버 닫았다 열기를 사용자 확인했다. 사용자의 추가 응답으로 나머지 세 앱은 이 물리 시험을 아직 하지 않은 것으로 확인됐다. PC 제어에 의존하는 코드는 없지만, 그 사실을 세 앱의 실제 USB 분리 시험 결과로 대신 기록하지 않는다. 커버 재연결 복구와 장시간 게임 부하는 추가 안정성 검증 범위로 남긴다. 기본 배치/입력 시험을 반복 요청하지 않는다.

설계의 전체 복구 시나리오가 모두 확인됐다는 의미로 전체 목표를 완료 처리하지 않는다. 서비스의 재시도는 최대 6회/15초, 이후 60초 대기다. 시스템 강제 종료 직후 회전 복원은 보장하지 않으며 다음 서비스 시작에서 저장한 회전 상태를 복구한다.
