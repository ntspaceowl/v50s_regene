# V50S ReGene

LG V50S 전용 에뮬레이터 선택형 듀얼스크린 제어 앱. 커버는 게임 상단, 본체는 게임 하단과 조작 버튼이다.

최신 설치본은 ReGene0.1.13/code14이다. 실사용 목록은 Citra·Azahar·melonDS·DraStic 네 항목이다. 중복 설치본과 WideMode를 삭제했다. 확대된 Azahar·melonDS는 사용자 확인을 통과했고, Citra 화면 및 종료 후 확장 잔류를 보완했다. 최종 Citra 물리 확인은 대기 중이다. 최신 기록은docs/current-status.md와docs/2026-10-04-usability-fixes.md를 참조한다.

현재0.1.9은 실기기 검증용 초기 버전이다. Citra/melonDS/DraStic/Azahar 선택 버튼, 첫 실행 권한 링크, 포그라운드 제어 서비스와 중지 버튼을 제공한다. 설치된 경우 Azahar와 melonDS 분리 시험판 선택 버튼도 표시한다. 기존 WideMode 앱 실행 없이 LG API를 직접 호출한다. 에뮬레이터 레이아웃은 기존에 저장한 설정을 사용하며 원본 ROM/세이브는 수정하지 않는다. 선택된 melonDS는 레이아웃 편집기도 두 화면 크기로 확장한다. Citra는 접근성 서비스로 실행 중 Hide Input Buttons 상태를 읽고 메뉴를 조작한다. 시험 버튼으로 숨김·복원과 실제 Bluetooth 연결 시 전체 숨김을 확인했다. Citra 실제 연결 해제 복원과 물리 버튼 입력은 남아 있다. Azahar 시험판은 실제 Bluetooth 자동 매핑, 사용자 방향 조작 확인 및 연결 중 패드 숨김·하단 ADB 터치를 확인했다.

## 빌드

Windows PowerShell에서 `./app/build.ps1`. Android SDK와 Android Studio JBR 경로는 스크립트 상단에서 설정한다. 결과는 `app/build/regene-debug.apk`. 개발용 서명키는 `app/build/debug.keystore`로 유지하며 저장소에 넣지 않는다.

## 사용

앱 사용 정보와 시스템 설정 변경을 한 번 허용하고 에뮬레이터 실행 버튼을 선택한다. 해당 에뮬레이터에서 게임을 고른다. 알림 또는 앱의 중지 버튼으로 제어를 끝낸다. 초기 시험은 대상 앱에 있는 동안 rotation3을 요청한다.

## 확인한 범위

- LM-V510N Android12에서 APK 설치 및 v2/v3 서명 검증.
- LG ActivityManager의 getWideScreenMode/setWideScreenMode 리플렉션 호출 성공. 루트/상시 PC 명령으로 제어하지 않는다.
- Citra 런처와 게임 Activity 전환 감지, 게임 진입 후2340x2160 확장 재적용.
- HOME에서 기존 회전 설정 복원, 대상 앱 복귀 후 확장 재요청.
- 앱 중지 버튼으로 서비스 종료 및 반복 작업 제거 확인.

0.1.7은 UsageEvents를10초 겹쳐 조회하고 타임스탬프로 이전 이벤트의 재적용을 막는다. 실행 버튼을 다시 누를 때60초의 최근 기록을 다시 읽는다. 실기기에서 Azahar가 실행됐는데 전경 기록이 ReGene에 머무른 사례를 발견해 보완했다. 이벤트 지연·중복·역순·커버 런처 제외 테스트와 설치 후 실제 전경 기록 일치를 확인했다. 모든 지연 시간/앱 전환을 보장하는 것은 아니다.

## 남은 검증과 구현

중력 센서에 따른 세로/가로 전환을 구현했고 자동 테스트를 통과했다. 실제 기기 회전 시험은 남아 있다. DraStic의 SENSOR 방향 요청은 시스템 회전 설정만으로 제어되지 않아 게임 중 작은 비터치 창으로 방향을 유지한다. 다른 앱 위 표시 권한이 필요하며 실기기 상하 배치/하단 입력/게임 유지 복귀를 확인했다. melonDS도 상하 배치/하단 게임 터치/게임 유지 복귀를 확인했다. Azahar는 가상 OFF 디스플레이가 LG 확장 해제를 유발하므로 호환성 미완료다. melonDS의 모든 버튼을 본체 영역에 저장하고 하단 게임 터치도 확인했다. 다만 게임 중 레이아웃 편집 후 검은 화면이 나타났고 HOME/최근 앱 복귀로 회복됐으며 이 경로의 안정성은 미완료다. 네 앱의 정확한 게임 터치/복귀, 화면 꺼짐/커버 재연결/USB 분리 시험도 남아 있다. 이 버전으로 전체 목표가 완료됐다고 판단하지 않는다.

서비스는 반복 확장에 최대6회/15초 제한과60초 대기를 적용한다. 커버 런처의 UsageEvents는 본체 전경 앱으로 잘못 취급하지 않는다. 비정상 프로세스 종료 후 다음 서비스 시작에 이전 회전 스냅샷을 복원한다. 중지/홈 복원은 일반 종료 상황에서 검증했으며 시스템 강제 종료 즉시 복원은 보장하지 않는다.

설계 및 진행 계획은 `docs/plans/2026-10-04-controller-design.md`, `docs/superpowers/plans/2026-10-04-controller.md`를 참조한다.
